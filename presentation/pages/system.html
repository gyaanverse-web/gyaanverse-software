System & Tech

Full Stack Breakdown

Every layer of the Gyanverse backend — from HTTP framework and ORM to payments, storage, and the CI/CD pipeline.

Core API

Fastify 5 + TypeScript + Drizzle

  • Fastify 5 — high-performance HTTP framework with schema validation
  • TypeScript — end-to-end type safety across routes, services, and DB queries
  • Drizzle ORM — type-safe SQL, schema-first migrations (db:generate / db:migrate)
  • Neon Postgres — serverless-compatible managed Postgres with PITR backups
  • Better Auth — sessions, email/password, phone OTP
Async & messaging

Jobs & Notifications

  • BullMQ + Redis — durable job queues
  • Resend — transactional email
  • MSG91 — SMS OTP delivery
Storage & payments

R2 + Razorpay

  • Cloudflare R2 — S3-compatible object storage, zero egress fees
  • Razorpay — subscription billing with webhook signature verification
Infrastructure & deployment

Cloud-native, low-ops

  • Railway — app + worker as two services from the same repo
  • Neon — database with branching and PITR
  • Cloudflare R2 — asset storage with zero egress
  • GitHub Actions — type-check, test, then deploy on merge to main
  • Drizzle migrations run as a controlled pre-deploy step
Developer experience

Local development commands

npm run dev          # Hot-reload API server (tsx watch src/server.ts)
npm run dev:worker   # Hot-reload background worker
npm run build        # Compile TypeScript → dist/
npm run start        # Run compiled production server
npm run test         # Vitest test suite
npm run db:generate  # Generate Drizzle migrations from schema changes
npm run db:migrate   # Apply pending migrations
npm run db:studio    # Drizzle Studio — visual DB browser
