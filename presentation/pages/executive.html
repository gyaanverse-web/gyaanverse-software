Key value propositions

Why Gyanverse?

  • Rapid tenant onboarding with strict per-institute data isolation
  • Secure authentication & role-based access via Better Auth (email/password + phone OTP)
  • Real-time exam orchestration powered by BullMQ background worker queues
  • Flexible tiered plans — Free, Starter ₹999, Growth ₹2,499, Pro ₹5,999
  • Cloud-native storage on Cloudflare R2 and transactional email via Resend
  • Token-based invite flows for frictionless teacher & student onboarding
Architecture approach

Modular monolith first

Start with a single deployable Fastify application partitioned into independent modules. Ship fast, keep operational overhead low. When specific components hit scale, extract them into dedicated services without a full rewrite — the module boundaries already exist.

Neon Postgres for persistence, BullMQ + Redis for async jobs, Cloudflare R2 for object storage.

Shipped modules
  • Auth — email/password + MSG91 OTP
  • Tenant — subdomain resolution, plan gates
  • Class — tenant-scoped CRUD
  • Membership — role-based access per tenant
  • Billing — Razorpay + webhooks
  • Invite — token-based onboarding
